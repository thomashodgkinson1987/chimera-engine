Chimera Engine

A specialised, data-driven, and modular C-based framework for creating procedurally generated, turn-based games with deep, systemic simulation.

Core Features

Systemic Simulation Core

Powered by the Flecs ECS framework to enable deep, complex, and emergent gameplay mechanics.

Data-Driven by Design

All aspects, from entities to world generation, are driven by external data, making the engine highly moddable.

Turn-Based Focus

A built-in Command Pattern game loop perfect for creating intricate, turn-based roguelikes and strategy games.

Get Started

Ready to build your own systemic, turn-based game? Clone the repository on GitHub. The included Dev Container provides the fastest way to get a fully-configured development environment.
